# Changelog

All notable changes follow semantic versioning. ActiveAdmin React remains prerelease
software until `0.1.0`; APIs identified below may change between beta releases.

## 0.1.0.beta1 — 2026-09-03

### Added

- Arbre-native `react_component` islands with deterministic markup, safe JSON props,
  caller-owned HTML attributes, and server-rendered fallback content.
- A bundler-neutral React 18/19 runtime with explicit component registration, multiple
  islands per page, Turbo lifecycle cleanup, and duplicate-registration protection.
- A validated Action Cable operation protocol with reconnect replay, duplicate and
  out-of-order suppression, terminal states, cancellation commands, and accessible status
  attributes.
- Explicit Rails engine contribution contracts with ownership, namespaces, surfaces,
  deterministic diagnostics, collision errors, and RBS signatures.
- An ActiveAdmin 4 dummy host, Ruby/JavaScript coverage gates, clean package installation,
  and RubyGems Trusted Publishing workflow.

### Prerelease contracts

- The Arbre helper name and mount data attributes are intended to stabilize during beta.
- The JavaScript registry, runtime lifecycle callbacks, async event envelope, replay action,
  and engine contribution metadata remain subject to compatible refinement before `0.1.0`.
- React stays optional; ActiveAdmin remains Rails-first and server-rendered.
